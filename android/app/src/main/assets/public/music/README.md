# Background Music

Place 5 MP3 files here:

| File | When it plays | Vibe |
|------|---------------|------|
| `idle.mp3` | App open, no active game (Home, Groups, Settings) | Calming ambient loop |
| `reveal.mp3` | Role reveal phase (players see their secret role) | Mysterious / tense |
| `discussion.mp3` | Discussion timer phase | Tense / ticking |
| `voting.mp3` | Voting + vote results + elimination reveal | Suspenseful |
| `results.mp3` | End-game results screen (points, winner) | Triumphant / dramatic |

## Requirements
- Format: MP3
- Loop-friendly (start/end should blend smoothly)
- Volume: app caps at 15% so SFX stay audible
- Length: 30-120 seconds (looped automatically)

If a file is missing, that phase has no music (no error).
